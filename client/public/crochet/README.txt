# Hidden crochet gallery

The gallery opens from the subtle **“little stitches ↗”** link in About. It does **not** appear in the main engineering project grid.

This package **includes all six user-supplied photographs**, optimized as `client/public/crochet/photo-01.jpg` through `photo-06.jpg`. Their captions and accessible descriptions live in `client/src/components/Home/CrochetGallery.js`.

The `DEPLOY_ON_MAC.command` deployment helper stages the gallery component, stylesheet, and photographs. It asks for explicit approval before pushing to GitHub.
